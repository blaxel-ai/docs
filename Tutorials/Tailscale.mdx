---
title: 'Run Tailscale in a sandbox'
description: 'Connect a Blaxel sandbox to your Tailscale tailnet and access it with Tailscale SSH.'
---

The Blaxel Tailscale image includes Tailscale and connects to your tailnet when the sandbox starts. Provide a Tailscale authentication key to access the sandbox from any authorized device on your tailnet.

## Prerequisites

Before starting, ensure you have:

- a [Blaxel account](https://blaxel.ai)
- a [Tailscale account](https://tailscale.com/)
- a Tailscale authentication key
- the Blaxel TypeScript or Python SDK if you create the sandbox from code

## 1. Generate a Tailscale authentication key

1. Open the [Tailscale keys page](https://login.tailscale.com/admin/settings/keys).
2. Select Generate auth key.
3. Enable Ephemeral so Tailscale removes the node after the sandbox disconnects.
4. Enable Reusable if the key will create more than one sandbox.
5. Copy the generated value, which starts with `tskey-auth-`.

Store the key in your local environment when using an SDK:

```sh
export TS_AUTHKEY=tskey-auth-...
```

<Warning>
  Treat `TS_AUTHKEY` as a secret. Do not commit it to source control or include
  it directly in application code.
</Warning>

## 2. Create the sandbox

### Blaxel Console

1. Open Sandboxes in the Blaxel Console.
2. Select Create sandbox.
3. Choose the Tailscale image.
4. Add an environment variable named `TS_AUTHKEY` and paste your authentication key as its value.
5. Create the sandbox.

The sandbox starts `tailscaled`, authenticates with the supplied key, and enables Tailscale SSH automatically.

### SDK

Create the sandbox with the `blaxel/tailscale:latest` image and pass `TS_AUTHKEY` as a runtime environment variable.

<CodeGroup>

```typescript TypeScript
import { SandboxInstance } from "@blaxel/core";

const authKey = process.env.TS_AUTHKEY;
if (!authKey) throw new Error("TS_AUTHKEY is required");

await SandboxInstance.create({
  name: "tailscale-sandbox",
  image: "blaxel/tailscale:latest",
  envs: [{ name: "TS_AUTHKEY", value: authKey }],
});
```

```python Python
import asyncio
import os

from blaxel.core import SandboxInstance

async def main():
    auth_key = os.environ["TS_AUTHKEY"]

    await SandboxInstance.create({
        "name": "tailscale-sandbox",
        "image": "blaxel/tailscale:latest",
        "envs": [{"name": "TS_AUTHKEY", "value": auth_key}],
    })

asyncio.run(main())
```

</CodeGroup>

## 3. Verify the Tailscale connection

Connect to the sandbox terminal:

```sh
bl connect sandbox tailscale-sandbox
```

Check that the sandbox is connected and retrieve its Tailscale IP address:

```sh
tailscale status
tailscale ip
```

The sandbox hostname defaults to its Blaxel sandbox name. Set `TS_HOSTNAME` when creating the sandbox to use a different Tailscale hostname.

## 4. Connect with Tailscale SSH

From another authorized device on your tailnet, connect with the sandbox hostname or Tailscale IP:

```sh
tailscale ssh root@tailscale-sandbox
```

Your [Tailscale SSH access policy](https://tailscale.com/kb/1193/tailscale-ssh) determines which users and devices can connect.

<Accordion title="Alternative: configure a base image manually">

Use the base image when you need to control the Tailscale installation or startup commands yourself. Create the sandbox with the `iptables` kernel enabled:

<CodeGroup>

```typescript TypeScript
import { SandboxInstance } from "@blaxel/core";

const authKey = process.env.TS_AUTHKEY;
if (!authKey) throw new Error("TS_AUTHKEY is required");

await SandboxInstance.create({
  name: "tailscale-sandbox",
  extraArgs: { iptables: "enabled" },
  envs: [{ name: "TS_AUTHKEY", value: authKey }],
});
```

```python Python
import asyncio
import os

from blaxel.core import SandboxInstance

async def main():
    auth_key = os.environ["TS_AUTHKEY"]

    await SandboxInstance.create({
        "name": "tailscale-sandbox",
        "extra_args": {"iptables": "enabled"},
        "envs": [{"name": "TS_AUTHKEY", "value": auth_key}],
    })

asyncio.run(main())
```

</CodeGroup>

Install and start Tailscale from the sandbox terminal:

```sh
apk add --no-cache tailscale iptables
tailscaled &
tailscale up --auth-key="$TS_AUTHKEY" --hostname=tailscale-sandbox --ssh
```

</Accordion>
